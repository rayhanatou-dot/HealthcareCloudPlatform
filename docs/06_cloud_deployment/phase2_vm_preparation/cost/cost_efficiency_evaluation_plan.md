# Cost-Efficiency Evaluation Plan

## Objective

Evaluate the infrastructure cost of the remote deployment and relate the verified cost to successful workload capacity and resource utilization.

## Required cost information

- VM provider or university infrastructure category
- CPU allocation
- RAM allocation
- Storage capacity and storage type
- Network transfer limits or charges
- VM usage period
- Monthly or hourly infrastructure price
- Additional backup or public-IP charges
- Whether the university resource is subsidized or free for research

## Cost metrics

- Hourly infrastructure cost
- Estimated monthly infrastructure cost
- Cost per successful request
- Cost per one million successful requests
- Cost per supported concurrent-user level
- Storage cost per GB where applicable
- Backup storage cost
- Network transfer cost where applicable

## Performance data required

- Successful requests
- Failed requests
- Requests per second
- Test duration
- Concurrent users
- CPU average and peak
- Memory average and peak

## Calculation rules

- Use only verified pricing or officially provided internal cost values.
- Record the currency and pricing date.
- Separate subsidized university access from commercial equivalent pricing.
- Do not report a monetary saving without a clearly defined comparison baseline.
- Do not calculate cost per request from unsuccessful or incomplete experimental runs.
- Preserve all assumptions and formulas used.

## Architectural cost-efficiency evidence

The platform may be described as cost-conscious based on its compact containerized architecture, open-source components, and absence of mandatory proprietary software licensing. Monetary cost-efficiency must remain pending until verified infrastructure pricing and remote utilization measurements are available.

## Evidence required

- Official pricing page, quotation, or university cost statement
- VM specification
- Billing period
- Test timestamps
- Successful-request totals
- Calculation worksheet
- Assumptions and limitations

## Status rule

No exact financial cost or saving may be reported until the infrastructure price and resource usage have been verified.
