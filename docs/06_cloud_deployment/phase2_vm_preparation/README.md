# Phase II: UESTC VM Preparation

## Current status

The local validation phase has been completed. The remote deployment and resource-constrained validation phase is part of the planned experimental methodology but remains pending because access to the institutional UESTC virtual machine has not yet been granted.

## Objective

Prepare all technical procedures, experimental protocols, evidence folders, and result templates required to begin the remote validation immediately after VM access is granted.

## Directory structure

- access: VM requirements, credentials checklist, SSH preparation
- deployment: Docker, environment, Nginx, migration, and startup procedures
- monitoring: CPU, memory, disk, network, and container monitoring
- experiments: workload, scalability, mixed-load, and endurance protocols
- backup_recovery: remote PostgreSQL and MinIO recovery validation
- cost: infrastructure pricing and cost-efficiency calculations
- evidence: command outputs, screenshots, logs, hashes, and configuration evidence
- results: validated experimental CSV files, summaries, and figures

## Important rule

No Phase II result may be reported as completed until it has been measured on the authorized remote VM.
